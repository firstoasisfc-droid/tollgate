Put the gates in your agent

Everything this console does comes from one file, lib/tollgate.js. No dependencies; Node 18 or later.

1. Create the gates once

const { createTollgate } = require("./lib/tollgate");

const gate = createTollgate({
  apiKey: process.env.CLOCKED_API_KEY,         // keep it server-side
  policy: { guard: { block: 0.5, hold: 0.3 } }, // optional, these are the defaults
});

2. Screen each channel before the agent acts

// Retrieved content: emails, pages, tool output
const doc = await gate.guard(emailBody);
if (doc.action === "block") return refuse(doc.hazard, doc.evidence);
if (doc.action === "hold")  return askHuman(doc);

// Outbound prompt: send the redacted text, never the original
const out = await gate.protect(draft);
const reply = await llm.complete(out.safeText);

// Proposed code: never run it unless the gate allows it
const code = await gate.inspect(script);
if (code.action !== "allow") return askHuman(code);
run(script);

Behaviour you can rely on

Fails closed. If Clocked cannot be reached, the gate returns hold, never allow.

Policy is data. Thresholds are passed in, clamped to 0–1, and hold can never exceed block.

Evidence, not a guess. Each decision carries the exact spans Clocked flagged, with offsets into your input.

Tested offline. npm test runs nine checks against a fake Clocked and spends no credits.
